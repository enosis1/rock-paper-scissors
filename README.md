# rock-paper-scissors
Part of The Odin Project's Curriculum

## Learning Goals
This is the first project within the JavaScript Foundations course. I hope to implement the game
"Rock Paper Scissors" using concepts learned within this JavaScript Foundations course. First this
will be implemented as a browser console applicationLater this will be updated to include a UI 
version as well.

## Planning Phase

### Understand The Problem
What is the problem that I am trying to achive?: Play Rock Paper Scissors within the console.

### Plan
Planning:
- Write the logic to get the computer's choice (Between Rock, Paper and Scissors)
- Write the logic to get the human's choice (Between Rock, Paper and Scissors)
- Declare the players score
- Write the logic to play a single round
- Write the logic to play the entire game out of 5 rounds
